Unofficial Namma Metro GTFS by Vonter (github.com/Vonter/bmrcl-gtfs), ODbL 1.0; schedules from BMRCL's published timetables, intermediate stop times approximated.
Source: https://raw.githubusercontent.com/Vonter/bmrcl-gtfs/main/gtfs/bmrcl.zip (feed_version 20260817, valid 2026-08-17 to 2027-08-17), fetched 3 Nov 2026.
Licence: Open Database License (ODbL) 1.0 — https://opendatacommons.org/licenses/odbl/1.0/ (attribution + share-alike for adapted databases). Verified via the GitHub licence API (spdx ODbL-1.0) and the repository README on 3 Nov 2026.
Provenance (from the README): timetables transcribed from images on https://www.bmrc.co.in/metro-timings/ (first/last trains and headways); intermediate stop timings are an approximation from stop spacing, dwell time and average speed; "discrepancies of the order of a couple of minutes" and missing short-loop trains are expected. Station geometry from OpenStreetMap (ODbL).
Changes: only agency, stops, routes, trips, calendar, calendar_dates, feed_info bundled unchanged; stop_times.txt gzip-compressed (content unchanged); shapes, fares, pathways, levels, translations not bundled (unused). The adapted database (this subset + the compiled web/transit/bmrcl.json) is offered under the same ODbL 1.0.
