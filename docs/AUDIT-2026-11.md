# Bharat Map — technical audit, November 2026

Audit date: 3 Nov 2026 (IST). Scope: the whole repository at `9ced124` (0.7.18): Express + SQLite server (`server/`),
shared isomorphic core (`shared/`), MapLibre web client (`web/`), Capacitor 7 Android shell (`android/`), CI
(`.github/workflows`), dependencies and git history. Brief read first: `README.md`, `docs/AUDIT.md`,
`docs/ARCHITECTURE.md`, `docs/TEST-REPORT.md`.

**Method.** Manual review of every API route and SQL statement, auth, payments, integrations, CSP/headers, service
worker, all 92 `innerHTML` / `insertAdjacentHTML` sinks, Android manifest / plugins / WebView settings, CI; plus tools:
`npm audit`, `npm outdated`, licence census from `package-lock.json`, **semgrep 1.x** (`p/javascript`, `p/nodejs`,
`p/xss`, `p/java`; server, shared, web, android), **gitleaks 8.21.2** over all 28 commits, **ESLint 9** (recommended
rules, temporary config, not committed), plus measurements from the existing E2E perf probe.

**Constraints honoured.** No rewrites; working behaviour kept (all 209 existing unit/API tests and the full E2E still
pass). No APK slimming (no city removal, R8 or font trimming) and no APK signing/attaching — those wait for the owner.
`re-staging/` untouched.

### Top findings
1. **AUD-02 (High)** — an unpaid online order reserved stock and a rider forever; any free account could lock the whole
   catalogue and fleet. Now: 30-min payment window, then auto-cancel and release; max 5 open unpaid orders per customer.
2. **AUD-03 (High)** — `/map/style.json` cached the *rewritten* body, so one request with a forged `Host` header pointed
   every user's tiles / glyphs / sprites at another host (map outage or attacker tiles for up to 24 h via CDN).
3. **AUD-01 (High)** — production seeded every demo customer / seller / rider with the README password `demo1234`
   (already listed as "High if deployed as-is" in `docs/AUDIT.md`, never fixed): anyone could sign in as any seller and
   change prices / stock or reject orders.
4. **AUD-17 (High)** — `body-parser` 1.20.8 (GHSA-27r3-jxmh-p828, DoS); CI's `npm audit --audit-level=high` gate would
   fail on the next run.
5. **AUD-04 (Med)** — roles were trusted from the 12-hour JWT: a demoted admin stayed admin, a deleted user stayed signed in.
